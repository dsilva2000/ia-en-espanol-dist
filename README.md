# ia-en-espanol-dist

Built static copy of **IA en Español** as published at <https://mancolab.com/ia/>, a project of Manco Lab.

- `ia/` holds the generated files only (HTML, RSC payloads, CSS/JS bundles, sitemap, robots, llms.txt, the newsletter signup endpoint and `.htaccess`). It contains no source code and no credentials.
- The release `cpanel-latest` carries `ia.tar.gz` and `ia.tar.gz.sha256`, which the hosting server pulls each day.
- This repository is generated automatically. Please don't edit it by hand.
